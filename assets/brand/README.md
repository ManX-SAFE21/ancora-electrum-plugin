# Àncòra — brand files

The logo of the plugin, from the Safe21 brand kit `ancora-brand_1`
(2026-10-18). Use the files as they are: do not change the colours, the
shapes or the accents.

- **Name:** Àncòra, the same in every language (in the logo: àncòra,
  lower case). In code and file names: `ancora`.
- **Slogan:** *Àncora per te, ancòra per loro.* (Italian in every
  language: the play on words only works in Italian).
- **Colours of the logo:** ink `#101214`, water `#1AB5A3`, paper `#FBFBF9`,
  mint (secondary) `#EEF6F4`.
- **Font of the logo:** Manrope ExtraBold (800); the SVG text is already
  converted to paths.

| Files | What |
|---|---|
| `svg/ancora-mark*.svg` | the anchor alone |
| `svg/ancora-wordmark*.svg` | the word alone |
| `svg/ancora-lockup*.svg` | anchor + word (horizontal, vertical) |
| `svg/ancora-icon*.svg` | app icon (rounded square) |
| `svg/ancora-icon-light-plugin.svg` | the plugin's icon: `ancora-icon-light.svg` with the anchor at 76% of the square instead of 66% (owner, 2026-10-18), used for `bal/icons/ancora-icon-light-*.png` |
| `png/` | the same, as images (icons 16–1024 px) |

`-dark` = for dark backgrounds; `-mono` = one colour (`currentColor`).
Minimum size: anchor 16 px, lockup 120 px wide. Keep free space around the
logo at least as high as the ring of the anchor.
